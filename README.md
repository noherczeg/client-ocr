# Browser-Based Client-Side OCR

A free, secure, client-side Optical Character Recognition (OCR) tool that runs entirely in your web browser.

## 🚀 Live Demo

**[Try it now →](https://noherczeg.github.io/client-ocr/)**

## Features

✅ **100% Private** - Images never leave your computer  
✅ **Fast & Free** - No server queues or subscriptions  
✅ **Easy to Use** - Drag & drop, paste, or click to upload  
✅ **Offline Ready** - Works without internet after initial load  
✅ **SEO Optimized** - Structured data and meta tags included  

## Supported Formats

- PNG
- JPG / JPEG
- WEBP
- BMP

## How It Works

The app uses [Tesseract.js](https://tesseract.projectnaptha.com/), a JavaScript library that brings OCR capabilities directly to your browser using WebAssembly. All text extraction happens locally on your device without uploading anything to any server.

## Technologies

- **HTML5** - Semantic markup with SEO optimization
- **Tailwind CSS** - Responsive styling
- **Tesseract.js** - Client-side OCR engine
- **Vanilla JavaScript** - No frameworks or dependencies

## Getting Started

### Local Development

Simply open `index.html` in your browser - no build process or dependencies required!

```bash
# Open in your default browser
open index.html
```

### GitHub Pages Deployment

This project is automatically deployed to GitHub Pages via GitHub Actions. Any push to the `main` branch triggers a new deployment.

View the deployed version at: https://noherczeg.github.io/client-ocr/
